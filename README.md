# Valheim Mod Manager

Mod manager per Valheim (Windows 64 bit, Steam). Installa BepInEx, scarica le mod da Thunderstore, installa quelle scaricate da Nexus e confronta le mod tra amici con un codice. Progetto amatoriale, non collegato a Iron Gate, Thunderstore o Nexus Mods.

## Usarlo

1. Scarica `Valheim-Mod-Manager.zip` dalla pagina **Releases**.
2. Estrai tutta la cartella, per esempio sul Desktop.
3. Doppio clic su **Avvia Mod Manager**.

Tieni Valheim chiuso mentre installi e fai una copia del mondo prima di cambiare mod.

## Modificarlo

Vedi [CONTRIBUIRE.md](CONTRIBUIRE.md).

## Sicurezza

- L'app risponde solo sul tuo PC (`127.0.0.1`) e cambia una chiave a ogni avvio.
- Le mod sono programmi veri: installa solo quelle di cui ti fidi.
